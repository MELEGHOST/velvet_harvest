# Velvet Harvest

**Симулятор выживания/фермы с элементами строительства**

## Описание
Игра в стиле Stardew Valley и RimWorld с пиксель-артом высокого разрешения (1920x1080).

## Сюжет
Вы получаете в наследство пустой участок земли у озера в лесной зоне. В 100 км находится небольшой городок **Тихогорск**, куда можно ездить за покупками. Начните с палатки и постройте свою ферму мечты!

## Основные системы

### 🏗️ Строительство и крафт
- Поэтапное строительство дома (фундамент → стены → крыша → отделка)
- Система крафта с открываемыми рецептами
- Станции: верстак → кузница → лаборатория для скрещивания семян

### 🌱 Фермерство
- Базовые культуры: овощи, ягоды, цветы
- **Система скрещивания семян** - создавайте гибриды с уникальными свойствами
- Уход: полив, удобрения, защита от вредителей
- Влияние погоды и времени суток

### 💰 Экономика
- Валюта: **мелоны** (монетки с буквой M и дынями по ободку)
- Продажа урожая, выполнение заказов NPC
- Продажа редких гибридных семян коллекционерам

### 👥 NPC и отношения
- **Василий** - охотник, первый контакт после постройки дома
- Торговцы в Тихогорске
- Система отношений с подарками и квестами
- Особые события при высоком уровне отношений

### 🌙 Ночные события и стелс
- Ночью появляются "собиратели" - конкуренты
- Система освещения и теней
- Ловушки, укрытия в доме
- Риск потери урожая/инструментов

## Управление
- **WASD** - Движение
- **Shift** - Спринт
- **E** - Взаимодействие
- **B** - Режим строительства
- **Esc** - Меню/инвентарь

## Структура проекта
```
velvet_harvest/
├── scenes/           # Сцены Godot
│   ├── player/       # Сцена игрока
│   ├── npcs/         # Сцены NPC
│   ├── environment/  # Окружение
│   ├── buildings/    # Постройки
│   ├── crops/        # Растения
│   └── ui/           # Интерфейс
├── scripts/          # Скрипты GDScript
│   ├── globals/      # Синглтоны (GameState, TimeSystem)
│   ├── systems/      # Игровые системы
│   ├── player/       # Логика игрока
│   ├── npcs/         # Логика NPC
│   └── ui/           # UI логика
└── assets/           # Ресурсы
    ├── sprites/      # Спрайты
    └── audio/        # Звуки
```

## Требования
- Godot 4.2+
- PC (Windows, Linux, macOS)

## Установка
1. Откройте проект в Godot Engine
2. Запустите сцену `scenes/main.tscn`
